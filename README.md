# @pixelpxed / Metawat R. Website
A personal website hosting new-architecture projects, currently consisting of:
- Send: A simple way to share links with a QR Code

[Deployed Website](https://pixelpxed.vercel.app)

## Running the server
To run this project, first install the package dependencies via one of the following:
```bash
bun i # Preferred
npm i
```

When completed, run the development server:
```bash
bun run dev # Preferred
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
